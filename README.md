# Модуль фитнес-трекера

Учебный проект модуля «Основы Go». Основа — шаблон
[Yandex-Practicum/go1fl-sprint5-final](https://github.com/Yandex-Practicum/go1fl-sprint5-final).

## Запуск

Требуется Go 1.24.1 или новее.

```sh
go run ./cmd/tracker
```

`cmd/tracker/main.go` сохранён без изменений: программа обрабатывает дневные
прогулки и тренировки из примеров, а ошибки отдельных записей выводит в журнал.

## Пакеты

- `spentenergy`: дистанция в километрах, скорость в км/ч и калории.
- `personaldata`: имя, вес в килограммах, рост в метрах и метод `Print`.
- `trainings`: разбор тренировок, поддержка бега и ходьбы, форматирование результата.
- `daysteps`: разбор и описание дневных прогулок.
- `actioninfo`: общий интерфейс `DataParser` и обработка набора записей.

Парсеры проверяют число полей, целое положительное количество шагов и
положительную продолжительность. Состояние записывается только после успешного
разбора всей строки. Неизвестный вид тренировки возвращает ошибку из `ActionInfo`.
Расчёты отклоняют некорректные вес, рост, длительность и количество шагов.
Ошибки одной записи не мешают обработке следующих.

## Проверки

```sh
go test -race -count=1 -cover ./...
go vet ./...
```

Исходные тесты Практикума сохранены без изменений. Дополнительно проверены
продолжение обработки после ошибок, отсутствие частичной записи при ошибке
парсинга и обработка нечисловых значений `float64`.

Проверено в РЕД ОС 8 (Linux arm64), Go 1.24.1. Логи находятся в `evidence/`.
Формулы учебные; программа не предназначена для медицинских расчётов.
